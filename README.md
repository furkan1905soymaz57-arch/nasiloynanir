# Havalı Arayüz

Basit bir HTML/CSS/JS arayüz örneği. İçinde "fifada domalan bokkanım" yazısı neon stileyle gösterilir.

Çalıştırmak için:

1. Proje klasörünü açın.
2. Tarayıcıda `index.html` dosyasını açın (çift tıklayın veya sürükleyip bırakın).

Alternatif olarak VS Code'da Live Server uzantısı varsa `index.html` üzerinde "Open with Live Server" seçeneğini kullanabilirsiniz.
